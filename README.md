# מכירים את בית״ר! 🟡⚫

משחק לימודי לילדים (גיל 5) להכרת שחקני בית״ר ירושלים, עונת 2026/27.
React + TypeScript + Vite + Tailwind, PWA, ללא שרת.

**לשחק:** https://iitayiiperez7.github.io/beitar-kids/

פרסום גרסה חדשה: `npm run deploy` (בונה ודוחף את `dist` לענף `gh-pages`).

## הרצה

```bash
npm install
npm run dev        # http://localhost:5173 (נגיש גם מהאייפון באותה רשת)
npm test           # בדיקות מנוע (התאמת דיבור, מספרים בעברית, חזרות מרווחות, שלבים)
npm run build      # בנייה לפרודקשן כולל Service Worker
```

זיהוי דיבור דורש HTTPS (או localhost). לבדיקה באייפון צריך לפרוס לאתר עם HTTPS (Netlify / Vercel / GitHub Pages).

## מבנה

| תיקייה | תוכן |
|---|---|
| `src/data` | סגל מאומת (`players.ts`), טיפוסים, שמות לקריין |
| `src/engine` | מנוע המשחק: נרמול עברית, התאמת תשובה מדוברת, מספרים בעברית, שאלות, חזרות מרווחות, שלבים |
| `src/speech` | שכבת `TTSProvider` / `STTProvider` (מימוש Web Speech), קריין עם כתוביות, אפקטים |
| `src/store` | שמירה: התקדמות והגדרות (localStorage), תמונות (IndexedDB) |
| `src/screens` | בית, לימוד, משחקי שאלות, זיכרון, מסך הורים |
| `src/ui` | רכיבי ממשק |

## נתוני הסגל

הסגל אומת ב-21/10/2026 מול אתר המועדון וטפסי המשחק של ההתאחדות (פירוט בראש `src/data/players.ts`).
מה שתוקן לעומת הרשימה ההתחלתית:
- ג'ונבוסקו קאלו וסמואל קאלו הם אותו שחקן (מספר 9).
- רביד אברג'יל לובש 18 (באתר המועדון מופיע בטעות 30).
- נוספו אורי עזו (23), אלכסיס סרנה (80) ויאן שיקוט (21). הם רשומים בהתאחדות ומופיעים בטפסי המשחק, אבל עדיין לא באתר המועדון.
- נוספו גם מיכאל ואקנין ואיתיי שושן, שרשומים רק בהתאחדות. הם כבויים במשחק עד שהורה יפעיל אותם.

## תמונות

לפי תנאי השימוש של אתר המועדון, אסור להשתמש בתוכן האתר ללא אישור בכתב, ולכן האפליקציה לא כוללת תמונות שחקנים.
עד שמוסיפים תמונה, השחקן מוצג כחולצה צהובה עם המספר שלו.
הורים מוסיפים תמונות במסך ההורים (🔒). כל תמונה נשמרת רק במכשיר, יחד עם המקור והתאריך שלה, ולילד מוצגות רק תמונות שההורה סימן כמאומתות.
